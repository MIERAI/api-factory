# order

A service generated by api-factory. The designer writes `design/<domain>/` and `db/schema/*.sql`; everything
else (`specs/`, `proto/`, `db/queries/`, `gen/`, `internal/handler/`, `cmd/server/wiring_gen.go`) is generated:

```sh
factory --project . design    # design/ → proto + specs
factory --project . check
factory --project . prepare   # → generated code
go mod tidy && go build ./...
```
